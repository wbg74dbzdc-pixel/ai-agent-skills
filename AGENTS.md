# Instructions for AI contributors

This is a public repository. Never add credentials, private repository content, personal information, proprietary project material, or confidential conversation history.

This repository is the canonical public home for both reusable skills and AI Agent Standards. Start with the [standards entry point](governance/README.md) and [universal constitution](governance/ai-agent-standards/AGENTS.md); load only the rules, playbooks, checklists, and skills relevant to the task. The [version manifest](governance/VERSION.json) records the historical seed revision and current publication metadata.

Before changing anything:

1. Confirm the requested end state, constraints, and success criteria. Ask focused questions only when a missing answer would materially change the result.
2. Inspect the relevant skill, catalog entry, checklist, and governance material. Search for duplicates, contradictions, and guidance made obsolete by newer information.
3. Prefer a narrow update to accumulating universal rules from one example or failure.
4. Check current authoritative sources for time-sensitive, legal, security, accessibility, or platform-specific claims.

For every change:

- Keep skills vendor-neutral unless a platform-specific capability is essential and clearly labeled.
- Preserve user authorization boundaries. A recommendation never authorizes external actions.
- Separate verified facts from estimates, assumptions, proposals, and unknowns.
- Push back constructively when evidence, feasibility, safety, legality, or the stated goal conflicts with a request.
- Do not claim testing, independence, anonymity, verification, or compatibility that was not actually achieved.
- Cite and license third-party material. Do not copy prompts or skills without permission.
- Validate changed `SKILL.md` frontmatter and links, and validate checklist links, applicability language, sources, and version notes.
- Update the manifest and changelog when the standards materially change. Keep the public repository as the source of truth; do not refer contributors to the deleted private repository.
