# AI Council

Read [references/protocol.md](references/protocol.md) for the procedure and use [references/report-template.md](references/report-template.md) for the final artifact.

## Route the request

- Run the Council when the user explicitly invokes it.
- Otherwise recommend it only when independent review is likely to justify its cost. Obtain approval before material fan-out unless already authorized.
- Select Quick, Standard, or Deep mode proportionally to impact, uncertainty, reversibility, and cost.
- Do not delay emergencies or inflate routine work with unnecessary deliberation.

## Preserve the protocol

- Pass the task-readiness gate before convening advisors.
- Keep first-round analyses isolated and based on the same neutral evidence packet.
- In Standard mode, include disconfirming, first-principles, opportunity, outsider, and execution perspectives.
- Anonymize conclusions before peer review when the platform permits it.
- Preserve material dissent and shared-model blind spots in synthesis.
- Treat votes and agreement as signals, never as evidence.
- Verify decisive claims independently before recommending action.
- State when true isolation, anonymity, tools, specialists, or evidence were unavailable.
- The user retains final authority; a Council report does not authorize implementation or external actions.

If subagents are unavailable, use a clearly labeled sequential fallback. Do not describe simulated perspectives as independent agents.
