# Repository Instructions

The canonical agent policy is `/AGENTS.md`. Follow it and the most specific applicable project or path rules.

- Establish the task contract before material implementation.
- Inspect current repository state; do not infer it from memory.
- Preserve product intent and unrelated work.
- Make small, reviewable changes.
- Add or update tests for behavior changes.
- Never invent APIs, files, results, citations, or completion.
- Report verification and remaining uncertainty.
