# Changelog

## 1.4.2 - 2026-10-16

- Added project ownership and chain-of-title checks for commissioned, contributed, third-party, and AI-assisted work.
- Added a reusable rights and license inventory and routed it through product-release and game launch checks.
- Added explicit review of EULA, publisher/store, mod, workshop, and user-content grants; clarified that checklists cannot guarantee immunity from copying or legal claims.
- Corrected the embedded constitution version to match the public standards manifest.

## 1.4.1 - 2026-10-16

- Routed the universal release constitution directly to the new product checklist index so adopted standards expose the security and release gates without relying on the repository README.

## 1.4.0 - 2026-10-16

- Made the public skills repository the canonical source after the former private source repository was deleted.
- Added a routed, evidence-based product checklist system so agents load only checks relevant to the software and release.
- Added baseline software security, API/service, mobile/desktop, game, AI-enabled product, and cross-product release/legal checklists.
- Added authoritative security, accessibility, platform, and regulator references; require agents to verify current versions and applicable jurisdictions.
- Clarified that checklist completion is not proof of legal compliance, certification, or exhaustive coverage.

- Added a portable `ai-council` skill, Council report template, cross-agent adapter routing, research attribution, and regression rubric.
