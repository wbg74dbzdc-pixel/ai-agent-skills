# Feature Development Playbook

1. Establish the task contract and acceptance criteria.
2. Inspect architecture, source of truth, neighboring behavior, and tests.
3. Establish a working baseline.
4. Identify data ownership, interfaces, failure modes, migration, security, privacy, accessibility, and observability impacts.
5. Implement the smallest end-to-end vertical slice.
6. Add normal, edge, failure, and regression tests.
7. Run targeted checks, then broader checks justified by risk.
8. Inspect behavior and diff; update docs and decisions.
9. Handoff with evidence, unverified areas, risks, and rollback notes.

Do not call a feature finished because code exists. Done means the agreed behavior is integrated, verified, documented, and present in the authorized destination.
