# Files and Git

- Search before creating new files and follow existing layout and naming.
- Preserve unrelated, unfinished, and uncommitted user changes.
- Use precise edits; avoid bulk rewrites that erase meaningful history or provenance.
- Never place secrets, credentials, private configuration, generated caches, or unnecessary binaries in version control.
- Inspect the complete diff for scope, accidental deletion, formatting damage, and sensitive data.
- Use clear commit messages tied to the task's outcome.
- Do not rewrite shared history, force-push, delete branches, discard changes, or merge without explicit authority.
- Prefer branches and pull requests for material collaborative changes.
- Keep generated files reproducible and document their source; verify binary artifacts independently.
- Finish with a comprehensible working state and identify any intentional uncommitted work.
