# Safety and Compliance Routing

This compatibility file points adopters to the expanded standards:

- operational authority and destructive actions: `authority-and-safety.md`;
- prompt injection, tools, secrets, and personal data: `security-and-privacy.md`;
- product and website release checks: `release-compliance.md`;
- website-specific procedure: `../playbooks/website-compliance.md`.

Apply only relevant categories, but explicitly decide relevance and record unresolved blockers. Never imply that an AI checklist or generated policy guarantees legal compliance.
